\subtituloA{Sintaxis de apertura y tipo}

\definicion{Atributo type}{El atributo \texttt{type="text/javascript"} informa al navegador que el contenido del script está organizado como javascript y no como html.}

\begin{codigo}
<script type="text/javascript">
// Código javascript va aquí
</script>
\end{codigo}

\textbf{Respuesta:} La ubicación afecta el momento de ejecución respecto a la renderización del contenido visible.)
