\subtituloA{Sintaxis de apertura}

\definicion{Atributo type}{El atributo \texttt{type="text/javascript"} comunica al navegador que el contenido del script está organizado en formato de texto javascript, no en html.}

\begin{codigo}

<script type="text/javascript">
\end{codigo}



\nota{Para el examen}{
¿Cuál es la función principal del atributo \texttt{type="text/javascript"} en la etiqueta \texttt{<script>}?

\textbf{Respuesta:} Informar al navegador que el código contenido es javascript y no html.
}
