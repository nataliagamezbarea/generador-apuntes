\subtituloA{Sintaxis de la etiqueta script}

\definicion{Atributo type}{El atributo \texttt{type="text/javascript"} informa al navegador que el contenido dentro de la etiqueta es código javascript en formato de texto, no html.}

\begin{codigo}
\script type="text/javascript"
\end{codigo}



\nota{Para el examen}{
¿Cuál es la función principal del atributo \texttt{type="text/javascript"} en la etiqueta \texttt{<script>}?

\textbf{Respuesta:} Informar al navegador que el contenido es código javascript y no código html.
}
