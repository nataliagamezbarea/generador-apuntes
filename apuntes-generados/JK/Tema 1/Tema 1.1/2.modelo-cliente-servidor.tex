\subtituloA{Modelo cliente-servidor}

\definicion{Modelo cliente-servidor}{Arquitectura web moderna compuesta por tres elementos: servidor, máquina cliente y conectividad de red.}
\lista{
  \textbf{Máquina cliente:} Ejecuta peticiones web mediante navegadores, debiendo soportar HTML, CSS, JavaScript y controles ActiveX. |
  \textbf{Conectividad de la red:} Medio por el cual se transmite la información, cuyo objetivo del navegador es presentar la información alojada en el servidor.
}

\nota{Para el examen}{
Identificar correctamente los tres elementos del modelo cliente-servidor y su función específica en la interacción web.
}
