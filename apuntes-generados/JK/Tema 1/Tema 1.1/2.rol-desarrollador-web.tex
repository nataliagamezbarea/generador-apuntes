\subtituloA{El rol del desarrollador web}

\lista{
  \textbf{Definición de estrategia:} Se establecen los objetivos del sitio, el tipo de contenido, las tecnologías necesarias y el enfoque de desarrollo. |
  \textbf{Desarrollo de interfaz:} Se crea la interfaz gráfica del usuario (UI/UX), diseñando la experiencia visual y funcional del sitio. |
  \textbf{Prototipado y presentación:} Se elaboran prototipos funcionales y se prepara la versión final del sitio web para su puesta en marcha.
}
