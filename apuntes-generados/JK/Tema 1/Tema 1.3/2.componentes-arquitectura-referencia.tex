\subtituloA{Componentes de la arquitectura de referencia}

\lista{
  **Interfaz de usuario:** Actúa como puente entre el usuario y el motor, gestionando barras de herramientas, progreso, preferencias y comunicándose con el sistema operativo. |
  **Motor del buscador:** Carga la dirección (URL/URI) y soporta navegación básica (anterior/siguiente/recargar), además de gestionar alertas de JavaScript. |
  **Motor de renderizado:** Presenta visualmente el recurso, interpretando HTML, XML, CSS y contenido embebido (audio/vídeo/imágenes). |
  **Subsistema de comunicaciones:** Implementa protocolos de transferencia de archivos y documentos de internet. |
  **Intérprete de JavaScript:** Analiza y ejecuta código JavaScript, respondiendo a eventos del ratón o teclado. |
  **Parser XML:** Carga en memoria una representación en árbol (DOM) del documento HTML para facilitar y agilizar el acceso a sus elementos. |
  **Componente de visualización:** Proporciona funcionalidades específicas para mostrar el contenido HTML. |
  **Subsistema de persistencia de datos:** Almacena historial, sesiones de usuario, preferencias, certificados de seguridad y cookies.
}
