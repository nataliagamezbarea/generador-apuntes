\subtituloA{Componentes de la arquitectura de referencia (Parte 2)}

\lista{
  \textbf{Parser XML:} Carga en memoria una representación en árbol (DOM) del documento HTML para facilitar y agilizar el acceso a sus elementos. |
  \textbf{Componente de visualización:} Proporciona funcionalidades específicas para mostrar el contenido HTML. |
  \textbf{Subsistema de persistencia de datos:} Almacena historiales, sesiones de usuario, preferencias, certificados de seguridad y cookies.
}
