\subtituloA{Motores de JavaScript y optimización}

\lista{
  \textbf{V8:} Motor de Chrome, Edge, Opera y Brave; también usado en Node.js. |
  \textbf{SpiderMonkey:} Motor de Firefox, desarrollado inicialmente por Brendan Eich en 1995. |
  \textbf{JavaScriptCore:} Motor de Safari, exclusivo para dispositivos iPhone e iPad. |
  \textbf{Optimización JIT:} Los motores modernos compilan a código máquina justo antes de ejecutar (JIT), logrando alta velocidad, superando a los intérpretes lentos antiguos. |
  \textbf{Actualización importante:} Microsoft abandonó Chakra en 2020; Edge utiliza V8 desde entonces.
}
