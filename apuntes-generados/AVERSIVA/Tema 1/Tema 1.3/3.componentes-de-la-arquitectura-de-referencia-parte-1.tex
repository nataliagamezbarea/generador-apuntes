\definicion{Interfaz de usuario}{Capa que media entre el usuario y el motor del navegador, gestionando barras de herramientas, preferencias y comunicación con el sistema operativo.}

\subtituloA{Componentes clave de la primera parte}

\lista{
  \textbf{Motor del buscador:} Carga la url/uri, soporta navegación (anterior/siguiente) y gestiona alertas de javascript. |
  \textbf{Motor de renderizado:} Interpreta y presenta visualmente el recurso (html, xml, css, multimedia). |
  \textbf{Subsistema de comunicaciones:} Implementa protocolos de transferencia de archivos y documentos de internet (ej. http/https).
}

\nota{Para el examen}{
Diferencie la función del motor del buscador (carga de url) del motor de renderizado (presentación visual del código recibido).
}
