\definicion{Minificar vs. Ofuscar}{Minificar reduce el tamaño del archivo quitando espacios y acortando nombres para optimizar la carga; ofuscar dificulta la lectura pero no impide la inspección del código.}
\subtituloA{Principio de seguridad web}

\lista{
  \textbf{Principio:} Toda validación realizada en el cliente es por comodidad del usuario, nunca por seguridad. |
  \textbf{Regla:} El servidor debe validar absolutamente toda la información recibida. |
  \textbf{Práctica:} Las APIs seguras no exigen claves en el código del navegador.
}
\nota{Para el examen}{
Explicar por qué una clave de API nunca debe exponerse en el código JavaScript del cliente, relacionándolo con la accesibilidad total del código por parte del usuario final.
}
