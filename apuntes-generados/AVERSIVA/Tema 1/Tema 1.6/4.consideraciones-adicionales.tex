  \textbf{Soporte nulo: |
  Se utiliza la etiqueta \texttt{<noscript>
} para informar al usuario si el navegador no soporta scripts.
  \textbf{Xhtml:} Para xhtml, se emplea la sintaxis \texttt{>}} dentro de la etiqueta \texttt{<script>}.
  \textbf{Licencias:} Se pueden añadir licencias como Creative Commons al código para indicar su autor.

\nota{Para el examen}{
¿Cuál es la forma más recomendable de integrar JavaScript y por qué?

\textbf{Respuesta:} Archivo externo, debido a la modularidad, facilidad de depuración y rapidez de carga, separando las responsabilidades del código.
}
