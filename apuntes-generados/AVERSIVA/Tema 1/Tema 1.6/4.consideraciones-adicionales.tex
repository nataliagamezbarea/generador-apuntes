\subtituloA{Consideraciones adicionales}

\lista{
  \textbf{Soporte nulo:} Se utiliza la etiqueta \cmd{<noscript>} para informar al usuario si el navegador no soporta scripts. |
  \textbf{XHTML:} Para XHTML, se emplea la sintaxis correspondiente dentro de la etiqueta \cmd{<script>}. |
  \textbf{Licencias:} Se pueden añadir licencias como Creative Commons al código para indicar su autoría.
}

\nota{Para el examen}{
¿Cuál es la forma más recomendable de integrar JavaScript y por qué?

\textbf{Respuesta:} Archivo externo, debido a la modularidad, facilidad de depuración y rapidez de carga, separando las responsabilidades del código.
}
