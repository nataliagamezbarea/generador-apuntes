\subtituloA{Componentes recomendados en entorno cliente}

\lista{
  \textbf{HTML y CSS:} Lenguajes fundamentales para dar formato al texto y definir el estilo visual de la página. |
  \textbf{JavaScript:} Lenguaje de scripting esencial para crear páginas dinámicas e interactuar con el usuario en el lado del cliente.
}

\nota{Para el examen}{
JavaScript es prioritario en el entorno cliente debido a su amplio soporte en navegadores y sistemas operativos actuales. Su utilidad es clave para la interactividad del portal web.
}
