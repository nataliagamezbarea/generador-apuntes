\subtituloA{Modelo cliente-servidor}

\definicion{Modelo cliente-servidor}{Arquitectura web moderna basada en tres elementos: servidor, máquina cliente y conectividad de red.} |
  \textbf{Servidor: |
  Aloja hardware, software, técnicas e implementaciones; se aconseja un lenguaje que soporte multihilos.
  \textbf{Máquina cliente:
} Ejecuta peticiones web mediante navegadores que deben soportar HTML, CSS, JavaScript y controles ActiveX.
  \textbf{Conectividad de la red:} Permite la transmisión de la información alojada en el servidor al navegador cliente para su presentación.
}

\nota{Para el examen}{
¿Dónde se implementan las peticiones de solicitud en el servidor?

\textbf{Respuesta:} En la máquina servidor. El navegador se encarga de presentar la información, no de alojarla para responder solicitudes.
}
